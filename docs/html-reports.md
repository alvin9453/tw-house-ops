# HTML 購屋評估報告

使用者選擇 HTML 呈現時，將偏好記錄在 `modes/_profile.md`。完整評估仍保存為 `reports/` 下的 Markdown，並照原流程寫 TSV、合併追蹤表及執行完整性檢查。

## 產生報告

在專案根目錄執行，日期使用評估報告檔名中的日期：

```bash
node render-pipeline-html.mjs YYYY-MM-DD
```

也可指定總覽檔名，例如：

```bash
node render-pipeline-html.mjs YYYY-MM-DD pipeline-review.html
```

產生器讀取 `reports/{###}-*-{YYYY-MM-DD}.md`，目前支援 `modes/buy.md` 的購屋報告格式。同一天的所有符合檔名的報告都會納入；不是只選擇剛執行的 pipeline。請先確認該日報告範圍，租屋報告須另行處理。

產出均位於 `output/`：

- 每個物件一份同名 `.html` 完整報告。
- 一份 `pipeline-{YYYY-MM-DD}.html` 互動總覽，連至每個物件報告。
- 已存在的檔名自動加上 `-2`、`-3` 等序號，保留舊檔；每次總覽連結指向該次產出的個別報告。

使用 Node.js 內建模組，不需安裝 npm 套件，也不會重新查詢物件或更新行情。不要把格式轉換當作本次重新驗證刊登上架。缺少符合日期的報告或參數錯誤時，指令會失敗，不應宣稱已完成交付。

## 閱讀與交付

總覽的物件卡片預設收合，保留價格、坪數、格局、通勤及分數供比較。點擊物件後，可以查看原始刊登、開啟該物件獨立報告，或逐項展開基本資料、價格、貸款、通勤、評分、疑點及看屋問題。

總覽支援全文搜尋、評分至少 3.5 的篩選、依評分或總價排序。總覽與獨立報告皆提供全部展開／收合、手機版面，以及列印時自動展開並於列印後恢復原狀。

所有樣式與互動程式內嵌，HTML 可直接離線開啟。分享整批報告時，應保持總覽與個別報告位於同一資料夾，讓相對連結正常運作；外部刊登與參考來源仍需連網。

交付時提供簡短摘要、總覽及個別 HTML 連結，避免在對話中重貼全文。`output/` 依現有 `.gitignore` 保留在本機；產生器不修改原報告、追蹤表或 pipeline。
